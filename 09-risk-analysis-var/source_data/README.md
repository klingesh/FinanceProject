# source_data: original downloads behind every number

The Yahoo Finance price files and the NSE bhavcopy extract were downloaded on 31-Oct-2026 (23:51 IST) by `src/fetch_data.py` into `data/raw/`; the bhavcopy rows for 3, 4 and 5 June 2024 were added on 1-Nov-2026 with the same function. The copies in `yahoo_finance/` and `nse/` are identical to those files (SHA-256 hashes in `download_log.csv`). Everything else was downloaded on 1-Nov-2026 by `src/fetch_source_data.py`, which also checks that the number or phrase used in this project appears in each saved file, and builds the two Excel copies. The analysis (`src/run_all.py` and the notebook) reads only `data/`, never this folder. Units: ETF prices in ₹ per unit, NIFTY 50 in index points, USD/INR in ₹ per US dollar, volume in units traded, traded value in ₹.

**News articles are not in the GitHub copy.** The 13 saved news pages in `news_and_macro/*.html` are copyrighted articles, so they stay on the author's PC and are left out of the public repository (see `.gitignore`). Each one is listed below with its full link and the fact taken from it. The RBI page in the same folder, the fund-house documents, the BIS page, the NSE files and the Yahoo Finance data are included.
