# source_data: original downloads behind every number

The Yahoo Finance price files were downloaded on 31-Oct-2026 at 23:34 IST by `src/fetch_data.py` into `data/raw/`. The copies in `yahoo_finance/` are identical (same SHA-256 hashes, listed in `download_log.csv`). Everything else was downloaded on 01-Nov-2026 by `src/fetch_source_data.py`, which also checks that the number or phrase used in this project appears in each saved file. The same script builds the Excel copy of the price files. The analysis (`src/run_all.py` and the notebook) reads only `data/`, never this folder. Units: share prices in ₹ (INR) per share, NIFTY 50 in index points, volume in shares, dividends in ₹ per share.

**News articles are not in the GitHub copy.** The 18 saved news pages in `news_and_macro/*.html` are copyrighted articles, so they stay on the author's PC and are left out of the public repository (see `.gitignore`). Each one is listed below with its full link and the fact taken from it. The RBI page in the same folder, the company filings, the exchange and index-provider documents and the Yahoo Finance data are included.
